# brown_premium_web_frontend

## Project Overview

**Name:** brown_premium_web_frontend


**Purpose:** A luxury‑real‑estate marketing website for Sri Parinithee Infra Developers Pvt. Ltd. The site showcases directors, projects, a gallery, services, benefits, contact information, and SEO‑optimized content. The current implementation is a static React + TypeScript single‑page application built with Vite.

## Current Technology Stack

- **Frontend:** React 19, TypeScript 6, Vite 8, Tailwind CSS 3, Framer Motion 14
- **Package Manager:** npm (using a `package-lock.json` lockfile)
- **Build Tools:** `npm run build` (TS compile + Vite bundling), `npm run dev` (Vite dev server), `npm run lint` (Oxlint), `npx tsc -b` (type‑checking)

## Planned Architecture (Future)
- **Frontend** (`frontend/`): will eventually house the React app (source files will be moved here).
- **Backend** (`backend/`): Node.js + Express API written in TypeScript.
- **Shared** (`shared/`): Common types, utilities, and UI components shared between front‑ and back‑end.
- **Database**: SQLite for local development, PostgreSQL for production (managed via Prisma migrations).
- **Image Storage**: Local `public/images/uploads/` during development; configurable object storage (e.g., S3) for production.
- **Admin Dashboard**: Secure, authenticated UI for managing directors, projects, gallery, services, benefits, website text, contact info, and SEO metadata.

> **Important Preservation Rule:** The existing public design, content, image paths, and animations must remain unchanged unless explicitly approved.
